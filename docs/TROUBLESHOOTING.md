# 排障

| 现象 | 原因 | 处理 |
|---|---|---|
| 右下角没有 ⬇ | 脚本没装/没生效 | 管理器里确认脚本已启用；刷新页面；确认 URL 是 `www.douyin.com` |
| 提示无法确定当前作品 | 页面没有可识别标识 | 先登录，点开具体作品，等播放再点 |
| 点下载没反应 | 解析接口不通 | 控制台看 `parse failed`；检查 `@connect parse.rcuts.com` 是否被拒 |
| 下载文件 0 字节 | 直链需要 Referer | 本项目已带 Referer；若仍失败，多为接口返回的链接过期 |
| 只下到视频没有图片 | 作品是图文但类型判断异常 | 看日志里的 `type=`；反馈作品链接 |
| Tampermonkey 提示跨域 | 未授权 `@connect` | 选择「总是允许」 |
| 换页面后下载了上一个作品 | 不应发生（v3.3 已修） | 立即停止并把 `[DVD]` 日志发来 |

## 取日志

F12 → Console → 过滤 `DVD` → 右键「Save as」或截图。日志里不含 Cookie。
