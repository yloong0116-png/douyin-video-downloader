# 使用说明

## 基本流程

1. 打开作品（推荐页当前视频 / 个人主页点开的作品 / 搜索结果点开的作品都行）
2. 点右下角 ⬇
3. 看到「已锁定 <作品ID>」说明识别成功
4. 勾选资源 → 开始下载
5. 面板关闭，文件进浏览器下载目录

## 识别失败怎么办

面板会提示「无法确定当前作品（本页未检测到作品标识）」，并且**不会下载任何东西**。

常见原因：

| 原因 | 处理 |
|---|---|
| 未登录 | 先登录，多数页面需要登录才渲染作品标识 |
| 停在搜索/关注页但没点开作品 | 点开某个作品再点 ⬇ |
| 页面还在加载 | 等视频开始播放再点 |
| 抖音改版 | 反馈并附 `[DVD]` 开头的控制台日志 |

## 多作品页面

个人主页/搜索页同时存在多个作品时，以「正在播放且可见」的那个为准。
如果两个候选说不清，脚本会拒绝而不是猜。

## 文案下载

勾 `text` 才会生成 `.txt`；文案为空时跳过并记日志。
